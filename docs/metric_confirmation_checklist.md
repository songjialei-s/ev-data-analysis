# 指标口径确认清单

状态说明：**已确认**仅用于由当前数据结构或已完成清洗规则直接证明的事实；**项目分析口径**表示为本项目可复现分析选择的默认定义，不代表公司正式 KPI；**待业务确认**表示无法仅凭数据判断，正式业务解释前必须确认。

| 主题 | 指标/字段 | 当前建议口径 | 为什么 | 是否影响后续分析 | 状态 |
| --- | --- | --- | --- | --- | --- |
| 数据基础 | 可信订单事实表 | 仅排除订单主键无效、云平台时间缺失或非正时长；其他运营异常保留并打标 | 与已完成清洗规则一致，可追溯且不静默删除 | 是，决定全部指标分母 | 已确认 |
| 主键 | `orderNum` | 一行一订单，以 `orderNum` 作为业务主键 | 当前真实源数据中非空且唯一 | 是，决定订单去重 | 已确认 |
| 时间 | `chargeBegin` / `chargeEnd` | 使用云平台时间计算时长；默认按 `chargeBegin` 归属日期、月份和小时 | 原生终端时间存在缺失及异常，云平台时间更完整 | 是，影响全部时间趋势 | 项目分析口径 |
| 跨期归属 | 跨日/跨月订单 | 暂按开始时间归属 | 能形成单一、可复现的时间口径 | 是，影响期末趋势 | 待业务确认 |
| 收入口径 | 默认“收入” | 文档和输出中不使用无修饰的“收入”；分别写“应付金额”和“实付金额” | `chargingPay` 与 `chargingPayActual` 业务含义不同 | 是，影响所有收益结论 | 项目分析口径 |
| 应付金额 | `chargingPay` | 所有可信订单的应付金额之和 | 应付反映订单计费，不等于到账 | 是 | 项目分析口径 |
| 实付金额 | `chargingPayActual` | 仅 `payStatus = 已支付` 且实付非空的记录求和 | 未支付不能以 0 当作已实现实付 | 是 | 项目分析口径 |
| 单位电量实付 | 每 kWh 实付金额 | `已支付订单实付金额合计 / 全部正电量订单的交付电量合计` | 衡量全部已交付电量对应的已实现支付金额；未支付电量仍属于已交付电量 | 是，影响单位电量收益解释 | 项目分析口径 |
| 未支付订单 | 订单量 | 进入订单量 | 支付状态不影响订单事实是否存在 | 是，影响订单量分母 | 项目分析口径 |
| 未支付订单 | 应付金额 | 进入应付金额 | 已形成计费金额，但不能称为到账 | 是 | 项目分析口径 |
| 未支付订单 | 实付金额 | 不进入总实付；单独统计未支付订单及金额 | 防止把应收与实收混淆 | 是 | 项目分析口径 |
| 支付生命周期 | 退款、冲正、部分支付、跨期支付 | 当前数据字段不足，不做推断 | 仅有当前支付状态和金额无法还原完整结算过程 | 是，影响财务解释 | 待业务确认 |
| 零电量订单 | 订单量、异常与启动分析 | 保留 | 有正时长的零电量记录是启动/通信/设备分析对象 | 是 | 已确认 |
| 零电量订单 | 平均订单指标 | 默认进入全订单平均；同时允许另算 `chargingPower > 0` 的有效充电平均，名称必须区分 | 两种口径回答不同问题 | 是 | 项目分析口径 |
| 零电量订单 | 每 kWh 金额 | 排除，要求 `chargingPower > 0` | 避免除以 0，且指标描述实际交付单位电量 | 是 | 项目分析口径 |
| 异常停止 | `endReason` 分类 | 先输出原始分布；未审批分类前不正式计算异常停止率 | 停止文本的业务归因无法只靠字段判断 | 是，影响异常率 | 待业务确认 |
| 设备异常 | 设备侧 `endReason` 清单 | 不按关键词自动定性；需业务与设备团队提供映射 | 车辆、通信、平台和设备边界可能重叠 | 是，影响设备类异常占比 | 待业务确认 |
| 原因分类字段 | `end_reason_category` | 在未确认前统一标记 `待业务确认`，同时保留原始 `endReason` | 不制造虚假分类，又为后续映射预留字段 | 是 | 项目分析口径 |
| 用户标识 | `user_key` | 作为分析层脱敏 `user_id` 的代理，只在私有分析结果中使用 | 盐化键可支持同一数据版本内去重，不能回连原值 | 是，影响活跃与复购 | 项目分析口径 |
| 用户缺失 | 空 `user_key` | 不进入活跃用户人数，但其订单仍进入订单指标 | 避免把空值当作同一用户 | 是 | 项目分析口径 |
| 用户分层 | 高频/中频/高价值阈值 | 本阶段不设置，先输出连续分布 | 缺少业务周期与运营目标，不能沿用模拟数据阈值 | 是，影响用户标签 | 待业务确认 |
| 活跃用户 | 活跃定义 | 数据期间内至少一笔可信订单且 `user_key` 非空的去重用户数 | 与当前可用事实表能力一致 | 是 | 项目分析口径 |
| 活跃枪口 | `stationName + plugNum` | 数据期间内出现过的复合键去重数量 | `plugNum` 不是全局唯一且没有真实配置表 | 是，影响单枪指标 | 已确认 |
| 设备规模 | 活跃枪口解释 | 只能称“期间活跃枪数”，不得称配置枪数、可用枪数或设备利用率分母 | 订单出现记录无法证明设备真实配置和在线情况 | 是 | 已确认 |
| 电量单位 | `chargingPower` | 项目按充电电量使用并暂以 kWh 展示 | 数值及费用分项表现为累计电量，但源字段名称易歧义 | 是，影响单位展示 | 待业务确认 |
| 峰谷平 | 各时段 Power/Bill/ServiceBill 字段 | 只做字段值求和及组成守恒，不扩展解释具体电价时段 | 数据能验证加总，但不能证明时段定义和计费规则 | 是，影响峰谷结论 | 待业务确认 |
| 金额单位 | 金额字段币种 | 文档暂写“金额”，不擅自标注币种符号 | 数据中没有独立币种字段 | 是，影响展示 | 待业务确认 |
| 费用守恒 | 应付=电费+服务费 | 容差 0.01 | 当前真实数据校验通过，符合字段组成关系 | 是，影响质量验证 | 已确认 |
| 实付守恒 | 实付+优惠=应付 | 仅在三个字段均非空时校验，容差 0.01 | 空值不能当 0；退款等流程尚未确认 | 是 | 项目分析口径 |
| 站点公开 | `stationName` | SQL 私有分析按真实名称计算；可提交结果使用 `STATION_nn` 代码 | 站点名称可能属于企业运营资产 | 是，影响公开输出 | 待业务确认 |
| 用户公开 | 用户级分析结果 | 完整用户级文件仅保留本地并由 Git 忽略；仓库只保留分布汇总 | 哈希化行为轨迹仍可能产生重新识别风险 | 是，影响发布 | 项目分析口径 |
