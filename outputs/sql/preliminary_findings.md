# SQL 阶段初步发现

## 数据事实

- 可信事实表包含 52,543 笔订单，总充电量为 1,530,787.028 kWh。
- 总应付金额为 1,432,275.24，已支付订单总实付金额为 1,427,739.86。币种待业务确认。
- 期间活跃用户 22,216 个；期间出现过的站点—枪口组合 221 个，后者不是配置枪数。
- 订单量最高的匿名站点为 STATION_08，订单数 8,539。
- 实付金额最高的匿名站点为 STATION_09，实付金额 259,129.66。
- 订单开始最集中的小时为 15:00，订单数 4,100。
- 67.11% 的脱敏用户在数据期间仅出现 1 笔订单；单个脱敏用户最多出现 1,460 笔订单。
- 最常见原始停止原因为“APP/微信/平台停止”，占可信订单 52.90%。该文本尚未归类为正常或异常。

## 初步判断

- 站点、小时与停止原因存在集中度差异，可作为下一轮钻取顺序；当前结果本身不足以支持扩容、停运或责任归因。
- 应付、实付、电费和服务费已分别计算，可以进一步检查支付差额与收益结构，但不能把应付金额称为到账收入。
- 极高订单频次的脱敏用户可能对应共享账号、企业账号或其他业务形态，需要确认后才能解释为个人复购。

## 待业务确认

- 停止原因的正常/用户/车辆/设备/平台/通信分类及设备侧边界。
- 金额币种、退款/冲正/部分支付和跨期支付口径。
- 峰谷平字段对应的实际计费时段，以及 chargingPower 的正式单位。
- 站点名称及聚合运营结果是否允许对外公开。当前文件已使用匿名站点代码。
- 数据起止月份不是完整自然月，月度规模不得直接与完整月份作同比式比较。

- 10/10 项验证通过；容差见 `metric_validation.csv`。
